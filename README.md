# Emily's Autumn Hunt

A small pixel-art adventure game. Plain HTML, CSS, and JavaScript with no build step.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder and visit http://localhost:8000.

## Deploy to GitHub Pages
1. Create a new repository and upload `index.html`, `style.css`, `game.js`, and this README to the root.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, then pick `main` and `/ (root)`.
4. Save. After a minute or two the game is live at `https://<your-username>.github.io/<repo-name>/`.

## Customize
The top of `game.js` has the text you can change: her name, your name, the note, and the ending messages.
